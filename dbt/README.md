## About dbt

**dbt** is a tool that allows **data transformations** within a data warehouse using SQL. 

It acts as a *development framework*, bringing software engineering best practices like version control, modularity, portability, CI/CD, and testing to the data transformation process. 

The objective with this tool is to build, test, and deploy models — like *Kimball Dimension Modeling, Star-schema, etc*.

## Architecture
We used **Medallion Architecture** for transformations:
- Bronze layer: Raw Data Ingestion (Extraction & Loading)
- Silver layer: Cleaned and Augmennted data (casting, re-naming, etc.)
- Gold layer: Business Level datan (aggregations, etc.)

### About the project
